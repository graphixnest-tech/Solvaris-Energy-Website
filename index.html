Product range

Five products, one energy loop

Every Solvaris product is designed to talk to the others over the same protocol, so adding a battery or a charger later doesn't mean replacing what you already own.

01 · Hybrid Inverter

The decision-maker of the system

Reads live production, household demand and battery state every few seconds, then routes power wherever it's worth the most — the outlet, the battery or the grid.

See specifications

02 · Battery

Storage that stacks as you grow

Wall-mounted LFP modules from 5.2 to 20.8 kWh, expandable in the field without swapping the original unit.

See specifications

03 · EV Charger

Charges on surplus, not schedule

Watches for exported solar in real time and shifts charging current to match it, so the car tops up on power that would otherwise go back to the grid for a few cents.

See specifications

04 · Microinverter

Panel-level output on shaded or complex roofs

One unit per panel, so shading or a fault on one module never drags the output of the rest of the array down with it.

See specifications

05 · Inverter

Solar-only conversion, sized for larger arrays

String inverters for sites without storage yet — built on the same firmware platform, so a battery can be added later without a second install visit.

See specifications

About Solvaris

A team that started with one inverter, not a product line

Solvaris was founded in Rotterdam in 2015 by a group of power electronics engineers who thought home energy hardware was being built for spec sheets, not households. We still design, test and support everything from one site — the same building where the first hybrid inverter was assembled by hand.
