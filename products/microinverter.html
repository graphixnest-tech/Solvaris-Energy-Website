Solvaris MicroLink

One inverter per panel, so a shadow across a single module or a fault on one unit never drags the output of the whole array down with it.

Why it's built this way

Designed around how microinverters actually get used

  • Panel-level MPPT — Each panel is tracked and optimised independently, which matters most on roofs with chimneys, dormers or partial tree shade.
  • Per-panel monitoring — See production down to the individual module in the MicroLink app — a single underperforming panel shows up immediately, not as a vague dip in total output.
  • Low-voltage, low-risk install — AC output at the panel means no high-voltage DC strings running across the roof, which simplifies inspection and fire safety.
