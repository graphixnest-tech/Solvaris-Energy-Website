# Solvaris Energy Website

Official website for **Solvaris Energy** — smart clean energy solutions including hybrid inverters, batteries, EV chargers, microinverters, and commercial energy management systems.

## 🌐 Live Demo
The live website is hosted via GitHub Pages at:  
👉 **[https://graphixnest-tech.github.io/Solvaris-Energy-Website/](https://graphixnest-tech.github.io/Solvaris-Energy-Website/)**

## 📂 Project Structure

```text
solvaris-energy/
├── index.html               # Home page
├── about.html               # About Us & leadership
├── contact.html             # Contact & inquiry form
├── products.html            # Products overview
├── resources.html           # Resources directory
├── solutions.html           # Solutions overview
├── css/
│   └── style.css            # Core design system & responsive styling
├── js/
│   └── main.js              # Navigation, FAQ accordion, dynamic interactions
├── products/
│   ├── battery.html         # Solvaris Battery storage
│   ├── ev-charger.html      # Smart EV chargers
│   ├── hybrid.html          # Hybrid inverters
│   ├── inverter.html        # String inverters
│   └── microinverter.html   # Module-level microinverters
├── resources/
│   ├── downloads.html       # Datasheets, firmware, brochures
│   └── faq-warranty.html    # Warranty policies & FAQ
└── solutions/
    ├── commercial.html      # Commercial & industrial energy
    ├── hospitality.html     # Hospitality & resort power solutions
    └── residential.html     # Residential solar & storage
```

## 🛠️ Built With

- **HTML5**: Semantic markup optimized for accessibility and SEO.
- **Vanilla CSS**: Clean, responsive styling with custom CSS variables and fluid typography.
- **Vanilla JavaScript**: Lightweight mobile navigation, accessible dropdowns, smooth scroll, and stats counter.

## 🚀 Running Locally

No build steps or dependencies required. Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/graphixnest-tech/Solvaris-Energy-Website.git
cd Solvaris-Energy-Website
# Open index.html in browser, or run a local server:
# python -m http.server 8000
# or npx serve
```
